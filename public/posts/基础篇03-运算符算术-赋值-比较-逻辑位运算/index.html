基础篇03-运算符（算术-赋值-比较-逻辑位运算）

October 5, 2026 · 1 min · 208 words · Hi, I'm SciFiReal
C++

学习运算符要注意运算符优先级、自增隐形、结合性、逻辑短路特性、浮点比较陷阱、整数除法规则。这是都是最容易出错的地方。介绍最常见的五种运算符：算术运算符、赋值运算符、关系运算符、逻辑运算符、三目运算符。

1. 算术运算符#

完成数据加减乘除、取模、自增自减，

1.1 基础算数运算符#

符号有+,-,*,\,%。注意一些规则：

  • 整数除法：两个int整数相除，结果强制为int，直接阶段小数。
  • 取模%仅限整数：不支持浮点类型
  • 正负取模规则：取模结果符号跟随被除数，规则计算，例如计算-7 % -3，过程-7/-3 = 2，余数=-7 - (-3 *2) = -1，结果余数为-1，符号跟谁被除数
	int a = 10;
	int b = 3;
	double res1 = a / b;
	double res2 = (double)a / b;

	// 3   3.33333   1   -1   -1   1
	std::cout << res1 << "   " << res2 << "   " << 10 % 3 << "   " << -10 % 3 << "   " << -7 % -3 << "   " << 7 % -3 << std::endl;

1.2 自增自减运算符#

  • a++：先取值参与运算，后自增1
  • ++a：先自增1，后取值参与运算

同理a–/–a也是这样的，注意在平时写代码过程中优先是使用a++/a–，避免使用++a/–a

	int a = 10;
	int c = a++, b = ++a;
	std::cout << a << "   " << b << "   " << c << std::endl;  // 12   12   10

1.2 赋值运算符#

包括以下两个点

基础赋值=

符合赋值+=，-=，*=， /=，%=

int a = 2'
a = a + 1;
a += 1;

1.3 关系运算符#

关系运算符>，<，>=，<=，==，!=用于数值比较

  • 任意数值比较，结果返回true（1），不成立返回false（0），可直接参与逻辑运算

  • 禁止对浮点型使用==和!=,因为浮点精度丢失导致数值看似相等，实际存储不同。判断大小使用极小误差区间判断

    // 判断两个浮点数的大小
const double EPS = 1e-6;  // float使用1e-5
double a = 10.1, b = 4.45;
if (fabs(a - b) < EPS)  
// 如果两个数字非常大，绝对误差就会失效，比如a=1e+9,b=1e+9+1e-5，差值1e-5>1e-6,但误差很少，要采用相对判断


// 比较大小
if (a > b + EPS)

1.4 逻辑运算符#

逻辑运算符用于多组条件组合判断，有三大逻辑运算符

  • 逻辑与&&：全真才真，任意假为假
  • 逻辑或||：全假为假，任意真为真
  • 逻辑非！：取反操作，真变假，假变真

需要注意的点是逻辑运算具备短路特性：

&&短路：左侧条件为false时，终止后续判断，右侧代码不执行

||短路：左侧条件为true时，终止后续判断，右侧代码不执行

1.5 运算符优先级与结合性#

要想解决运算逻辑错乱、判断结果异常，必须要了解优先级和结合性

优先级从高到低：自增自减>算术运算>关系运算>逻辑运算>赋值运算

  • 优先使用小括号，默认最强优先级
  • 同级优先级运算符，遵循从左至右结合性

1.6 三目运算符#

条件？表达式1：表达式2

一般用来做简短的二分支判断

int a = 1;
std::string state = a == 1 ? "设备启动" ："设备未启动"; // "设备启动"

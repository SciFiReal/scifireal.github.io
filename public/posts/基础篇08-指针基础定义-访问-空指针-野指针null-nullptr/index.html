基础篇08-指针基础（定义-访问-空指针-野指针NULL-nullptr)

October 5, 2026 · 2 min · 225 words · Hi, I'm SciFiReal
C++

本章讲解内存地址、取地址、解引用、理清指针和数组的底层联系，剖析野指针和空指针根源。

1. 指针#

指针的本质是：一切变量都有内存地址

我们可以把电脑内存想成一个宿舍楼，变量就是住在宿舍的人；内存地址就是宿舍楼的门牌号；指针是存放门牌号的纸条，指针变脸存的不是数据本身，是数据的内存地址。可以得出结论是==指针变量等于存内存地址的变量==。

  1. 指针有两大核心操作：
  • 取地址&：取出变量的内存地址，格式：&变量名
  • 解引用*：根据指针存储的地址找到数据本身，并修改，格式： *指针变量名
  1. 指针的标准格式如下：
// 指向的数据类型* 指针变量；
int* p;  // 指向的int的指针变量
double* pd;  // 指向的double的指针变量
char* ch;  // 指向的字符型的指针变量

指针规范写法，int* p; int *p; 这两种写法都是可以的。但为了避免歧义，统一使用 int* p; 定义形式，*靠近数据类型，这样看起来美观。

  1. 示例：
int p = 100;
int* ptr = &p;

std::cout << "变量p本身的值：" << p << std::endl;      // 100
std::cout << "变量p本身的内存地址：" << &p << std::endl;  //0000005F320FFD04
std::cout << "指针ptr本身的值：" << ptr << std::endl;  //0000005F320FFD04
std::cout << "指针ptr指向的值：" << *ptr << std::endl;  // 100

*ptr = 10;
std::cout << "修改*ptr指向数据的值：" << p << std::endl; // 10

输出结果：

变量p本身的值：100
变量p本身的内存地址：0000005F320FFD04
指针ptr本身的值：0000005F320FFD04
指针ptr指向的值：100
修改*ptr指向数据的值：10

2. 指针和数组的关系#

数组名本质上是数组首个元素的内存地址，本身是一个常量指针，不需要取地址，直接赋值给指针变量。因此可以使用**指针变量（数组名）**来遍历数组，取代用数组下标来遍历数组，这样的效果会高很多。

示例如下：

const int NUM = 5;
int arr[NUM] = { 10, 20, 30, 40, 50 };
int* p = arr;

for (int i = 0; i < NUM; i++)
{
  std::cout << *(p + i) << std::endl;  
 	// std::cout << *(arr + i) << std::endl;  效果一样
}

输出结果：

10
20
30
40
50

由上面例子可以等到等价公式： arr[i] == *(arr +i) == *(p + i)

3. C风格中字符串#

	char str1[] = { 'A','B','C','\0' };
	char str[] = "DEVICE_START";
	char* pStr = str;
	char* pStr1 = str1;
	int str2[] = { 1, 3, 4, 6 };
	// 指针直接操作字符串，自动识别\0结束符
	std::cout << pStr << std::endl; // DEVICE_START
	std::cout << pStr1 << std::endl; // ABC
	std::cout << str2 << std::endl; // 00000089251FF888

4. 空指针nullptr#

本质是不指向任何有效内存地址的指针，统一使用nullptr，代替旧的null。在定义初始化指针，防止随机指向任意的内存，代码中所有指针都需要初始化为nullptr。不能使用*nullptr会导致程序崩溃。

// 标准写法
int* p = nullptr; // 禁止使用*P

5. 野指针#

本质是没有初始化的指针，会随机指向内存一块未知的内存地址，可能会修改内存数据。防止出现BUG，所有的指针必须初始化，即赋值unllptr；使用指针前必须判断是否为空；指针使用完毕了，必须重置为nullptr；

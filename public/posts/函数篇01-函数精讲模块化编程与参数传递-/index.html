函数篇01-函数精讲：模块化编程与参数传递

October 5, 2026 · 2 min · 293 words · Hi, I'm SciFiReal
C++

为什么需要函数呢？

  • 代码复用：同一段逻辑写一次就行，多次调用，执行
  • 模块化：把大程序拆成一个个小模块，每个函数只做一件事
  • 抽线：调用这只需要知道函数名，返回值，传参，不需要知道内部代码怎么处理

1. 函数基础：定义、声明与调用#

  1. 函数的组成：返回类型，函数名，函数体，参数列表
// 返回类型 函数名(参数列表)
double celsiusToFahrenheit(double c)
{
    // 函数体：具体逻辑
    return c * 9.0 / 5.0 + 32.0; // return 返回值
}
  1. 函数定义、声明与调用的示例：
#include <iostream>
using namespace std;

// 1. 函数声明（告诉编译器：有这个函数存在）
double celsiusToFahrenheit(double c);
bool checkTemp(double temp, double min, double max);

int main()
{
    double c = 25.5;
    double f = celsiusToFahrenheit(c); // 函数调用
    cout << c << "C = " << f << "F" << endl;

    if (checkTemp(85.0, 0.0, 100.0))
        cout << "温度正常" << endl;

    return 0;
}

// 2. 函数定义（具体实现）
double celsiusToFahrenheit(double c)
{
    return c * 9.0 / 5.0 + 32.0;
}

bool checkTemp(double temp, double min, double max)
{
    return (temp >= min && temp <= max);
}

真实开发中，函数声明放在自定义头文件.h中；函数实现放在.cpp文件中；其它文件只需include头文件就能调用函数。

上述例子如果把函数定义放在main函数之前，可以忽略函数声明。

  1. 无返回值的函数

    有些函数是不需要返回值的，用void作为返回类型

    void printDeviceInfo(int id, const char* name, double temp)
{
    cout << "设备" << id << ": " << name
         << " 温度=" << temp << "度" << endl;
    // void 无返回值函数：可以不写return；也可写 return; 用于提前退出
}

2. 参数传递的三种方式#

实参：调用函数实际传入的值

形参：写在函数的参数列表中

之前就说过了有三种传递方式：

  • 值传递，不能修改函数外的数据值；

  • 指针传递，能改变；

  • 只读const指针；在大型工业中，一般使用const只读指针传递，避免大数据的拷贝，又避免数据的安全性。

3. 函数返回值的多种形式#

  1. 返回基本数据类型

    int add(int a, int b) { return a + b; }
double average(double x, double y) { return (x + y) / 2.0; }
bool isRunning(int deviceId) { return deviceId > 0; }

  2. 返回指针

    不能返回局部变量的指针，因为局部变量在函数结束时已经被收回了

    // 正确：返回堆上动态分配内存，**调用方必须手动delete[]释放**
int* createArray(int size)
{
    return new int[size]; // 堆内存，函数退出后内存不会自动销毁
}

// 正确：返回static静态局部变量地址，变量生命周期贯穿整个程序
int* getCounter()
{
    static int count = 0; // 静态变量：只初始化一次，函数退出不销毁
    count++;
    return &count;
}

// 错误！严禁返回栈局部变量的地址
int* badFunction()
{
    int x = 10; // 栈上局部变量，函数退出后栈内存自动回收
    return &x;  // 野指针！返回的地址失效，访问会产生未定义行为
}

  3. 返回结构体（结构体章节详细学过）

    struct DeviceStatus
{
    int deviceId;        // 设备编号
    double currentTemp;  // 当前温度
    bool isNormal;       // 设备状态是否正常
};

// 检测设备，返回完整状态结构体
DeviceStatus checkDevice(int id, double temp)
{
    DeviceStatus s;
    s.deviceId = id;
    s.currentTemp = temp;
    s.isNormal = (temp >= 20.0 && temp <= 80.0);
    return s; // 返回整个结构体对象
}

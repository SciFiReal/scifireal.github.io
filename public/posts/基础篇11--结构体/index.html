基础篇11-结构体

October 5, 2026 · 4 min · 666 words · Hi, I'm SciFiReal
C++

为什么需要结构体？

在现实中，一个实体可能会包含多个字段，比如一台设备的完整参数可能包含10个以上字段：设备ID、型号名称、当前温度、当前压力、运行状态、报警标志、通信地址、采样周期、固件版本、最后通信时间……如果每个字段都用独立变量存储，光是函数传参就要写10个形参，维护难度可想而知。

结构体的核心价值就是把这些相关的一组数据打包成一个整体。

1. 结构体的基础语法#

通过struct关键字把不同类型的字段组合在一起。

#include <iostream>
#include <cstring> // strcpy_s 字符串拷贝

// 工控场景：定义设备信息结构体
struct Device
{
    int deviceId;               // 设备编号
    char deviceName[50];        // 设备名称
    double temperature;         // 当前温度
    double pressure;            // 当前压力
    bool isRunning;             // 运行状态
    char commAddr[20];          // 通信地址
};

int main()
{
    // 方式1：逐成员赋值（初始化）
    Device dev1;
    dev1.deviceId = 1001;
    // strcpy_s(目标缓冲区, 缓冲区最大长度, 源字符串)
    strcpy_s(dev1.deviceName, sizeof(dev1.deviceName), "加热炉A");
    dev1.temperature = 82.5;
    dev1.pressure = 0.75;
    dev1.isRunning = true;
    strcpy_s(dev1.commAddr, sizeof(dev1.commAddr), "192.168.1.101");

    // 方式2：列表初始化（推荐，C++11风格）
    Device dev2 = {1002, "加热炉B", 85.2, 0.82, true, "192.168.1.102"};

    // 方式3：省略等号的列表初始化 C++11
    Device dev3 {1003, "冷却泵C", 25.1, 0.35, false, "192.168.1.103"};

    // 打印设备信息，\u2103 代表℃，部分终端会乱码，可替换为 "℃"
    std::cout << "设备" << dev1.deviceId << ": " << dev1.deviceName
              << " 温度=" << dev1.temperature << "℃" << std::endl;

    std::cout << "设备" << dev2.deviceId << ": " << dev2.deviceName
              << " 温度=" << dev2.temperature << "℃" << std::endl;

    std::cout << "设备" << dev3.deviceId << ": " << dev3.deviceName
              << " 温度=" << dev3.temperature << "℃" << std::endl;

    return 0;
}

---  结果
设备1001: 加热炉A 温度=82.5℃
设备1002: 加热炉B 温度=85.2℃
设备1003: 冷却泵C 温度=25.1℃

成员访问运算符.，普通结构体变量使用句号符号访问成员。结构体变量必须初始化才能使用。

2. 结构体数组与结构体指针：批量管理多设备#

结构体数组本质是一个普通数组，比如需要管理多台同类型的设备，每个元素就是一个结构体。

#include <iostream>
#include <cstring>

// 工控场景：设备信息结构体
struct Device
{
    int deviceId;               // 设备编号
    char deviceName[50];        // 设备名称
    double temperature;         // 当前温度
    double pressure;            // 当前压力
    bool isRunning;             // 运行状态
    char commAddr[20];          // 通信地址
};

int main()
{
    // 1. 结构体数组：管理4台设备
    Device devices[4] = {
        {1001, "加热炉A", 82.5, 0.75, true, "192.168.1.101"},
        {1002, "加热炉B", 85.2, 0.82, true, "192.168.1.102"},
        {1003, "冷却泵C", 25.1, 0.35, false, "192.168.1.103"},
        {1004, "冷却塔D", 28.6, 0.41, true, "192.168.1.104"}
    };

    // 遍历数组打印所有设备信息
    for (int i = 0; i < 4; i++)
    {
        std::cout << "设备" << devices[i].deviceId << ": "
                  << devices[i].deviceName << " 温度="
                  << devices[i].temperature << "℃" << std::endl;
    }

    // 2. 结构体指针：使用箭头运算符 ->
    Device dev = {2001, "反应釜", 125.5, 1.2, true, "192.168.2.1"};
    Device* pDev = &dev; // 取dev的地址赋值给结构体指针

    // 两种访问成员方式完全等价
    std::cout << "\n(*pDev).deviceId = " << (*pDev).deviceId << std::endl; // 解引用 + .
    std::cout << "pDev->deviceId = " << pDev->deviceId << std::endl;       // 箭头运算符（推荐）

    // 通过指针修改原始结构体数据
    pDev->temperature = 130.0;
    pDev->isRunning = false;

    // 验证修改结果
    std::cout << "\n修改后：" << pDev->deviceId << " " << pDev->temperature << "℃ 运行状态:" << std::boolalpha << pDev->isRunning << std::endl;

    return 0;
}

输出结果：

设备1001: 加热炉A 温度=82.5℃
设备1002: 加热炉B 温度=85.2℃
设备1003: 冷却泵C 温度=25.1℃
设备1004: 冷却塔D 温度=28.6℃

(*pDev).deviceId = 2001
pDev->deviceId = 2001

修改后：2001 130℃ 运行状态:false

什么时候使用.和->?

普通结构访问使用.，有指针就用->。使用指针的好处是直接可以修改原始结构体的数据，不用拷贝结构体中所有的数据。

3. 结构体作函数参数与返回值：数据跨函数传递#

结构体最重要的应用场景是作为函数参数或返回值，把多个字段打包成一个结构体，原本需要5，10个参数的函数，现在只需要一个结构体参数就能实现。

传参有三种方式：值传递；指针传递；const指针传递；

// 1. 值传递：只读场景可用，函数内部会拷贝整个结构体对象，开销大
void printDevice1(Device dev)
{
    std::cout << "设备" << dev.deviceId << ": " << dev.deviceName << std::endl;
}

// 2. 指针传递：可修改原始结构体数据，工控场景常用
void updateTemperature(Device* pDev, double newTemp)
{
    // 安全检查：防止空指针访问崩溃
    if (pDev != nullptr)
    {
        pDev->temperature = newTemp;
    }
}

// 3. const指针传递：只读，禁止修改原始数据，性能好且安全【推荐只读场景】
void printDevice2(const Device* pDev)
{
    if (pDev != nullptr)
    {
        std::cout << "设备" << pDev->deviceId << " 温度="
                  << pDev->temperature << "℃" << std::endl;
        // pDev->temperature = 100; // 编译报错，const保护原始数据不被修改
    }
}

// 4. 结构体作为返回值：一次性返回多项监测结果
struct StatusCheck
{
    int deviceId;
    double currentTemp;
    bool isOverHeat;
    bool isNormal;
};

StatusCheck checkDevice(const Device* pDev)
{
    StatusCheck status = {0}; // 全部成员初始化为0/false
    status.deviceId = pDev->deviceId;
    status.currentTemp = pDev->temperature;
    status.isOverHeat = (pDev->temperature > 80.0);   // 超温判断
    status.isNormal = (pDev->pressure > 0.3 && pDev->pressure < 1.0); // 压力正常区间
    return status;
}

结构体作为返回值的意义： C++函数本身只能返回一个值，但通过结构体，你可以把多个结果打包在一起返回。在真实工业项目中，温度检测函数可能需要同时返回：检测到的温度值、是否超过阈值、数据是否有效、检测时间戳等多个信息。结构体就是为这种场景而生的。

4. 嵌套结构体#

真实开发中，一个设备的信息可能包含多个子模块。比如设备除了基本信息（编号、名称）外，还有实时数据组（温度、压力、流量）、配置参数组（报警阈值、采样周期）、通信参数组（IP地址、端口号、协议类型），因此需要嵌套结构体，本质是一个结构体中包含另一个结构体。

// 实时数据组
struct RealTimeData
{
    double temperature;    // 温度
    double pressure;       // 压力
    double flowRate;       // 流量
};

// 配置参数组
struct ConfigParams
{
    double tempAlarm;      // 温度报警阈值
    double pressureLow;    // 压力下限
    double pressureHigh;   // 压力上限
    int samplePeriod;      // 采样周期(ms)
};

// 通信参数组
struct CommParams
{
    char ipAddr[20];       // IP地址
    int port;              // 端口号
    char protocol[20];     // 通信协议
};

// 完整设备信息：包含三个子结构体（结构体嵌套，工控项目常用）
struct FullDevice
{
    int deviceId;
    char deviceName[50];
    RealTimeData realTime;
    ConfigParams config;
    CommParams comm;
    bool isRunning;
};

int main()
{
    // 嵌套结构体列表初始化
    FullDevice dev = {
        1001,
        "主反应釜",
        {85.2, 0.75, 12.8},
        {80.0, 0.3, 1.0, 100},
        {"192.168.1.101", 502, "MODBUS"},
        true
    };

    // 多级访问：逐层 . 访问嵌套成员
    std::cout << dev.deviceName << " 温度：" << dev.realTime.temperature << "℃" << std::endl;
    std::cout << "报警阈值：" << dev.config.tempAlarm << "℃" << std::endl;
    std::cout << "通信地址：" << dev.comm.ipAddr << ":" << dev.comm.port << std::endl;

    // 通过指针访问嵌套成员：箭头+点组合 pDev->realTime.pressure
    FullDevice* pDev = &dev;
    std::cout << pDev->realTime.pressure << "MPa" << std::endl;

    return 0;
}

真实开发里，最多3层嵌套结构体，超过3层代码的可读性就非常低下。

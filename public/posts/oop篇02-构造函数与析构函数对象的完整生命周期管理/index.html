OOP篇02-构造函数与析构函数：对象的完整生命周期管理

October 6, 2026 · 2 min · 330 words · Hi, I'm SciFiReal
C++

为什么需要构造函数和析构函数呢？

如果没有构造函数：成员变量不会初始化，里面是随机垃圾值。保证只要对象创建，一定完成初始化。

如果没有析构函数：对象本身销毁的时候，只会销毁对象本身，不会自动释放对象里面指针指向的堆内存，堆内存不会自动回收，就造成内存泄漏。（析构函数只管你手动申请的堆内存）。

构造函数：负责初始化，对象出生的时候自动调用；

析构函数：负责清理，对象死亡的时候自动调用；

两者从管理对象从诞生到销毁的全过程。

1. 构造函数#

特点：

  • 名字与类名一模一样，没有返回值（void也不能写）；
  • 创建对象，编译器自动调用，不用手动调用；
  • 作用：给成员变量赋值、申请堆内存、打开文件等操作；
class Person
{
private:
    int age;
public:
    // 无参构造函数：名字=类名Person，无返回值
    Person()
    {
        cout << "构造函数执行：对象出生了" << endl;
        age = 0; // 初始化年龄
    }
    void setAge(int a){ age = a; }
};	

int main()
{
    Person p; // ✅ 创建栈对象，自动调用Person()构造函数
    return 0;
}

// 带参构造函数
Person(int a)
{
    cout << "带参构造" << endl;
    age = a;
}

编译器会默认生成无参构造函数，如果你自己写了构造函数，就不会提供模板。

  1. 构造函数重载：和普通函数一样，构造函数可以有多个版本（重载），编译器根据创建对象时传入的参数自动匹配。
  1. 构造函数初始化列表：初始化列表，是在构造函数函数体执行之前，就给成员变量做初始化的语法。上述代码是在构造函数体内进行赋值，属于成员变量已经创建好了，再重新赋值。初始化列表是创建成员变量的同时直接给初值。
class Person
{
private:
    int age;
public:
    // 冒号后面就是初始化列表
    Person() : age(18)
    {
        // 函数体里面是空的
    }
};

  1. 什么时候必须用列表初始化呢？

    • 成员是const变量；

    • 成员是引用类型；

    • 成员是没有默认构造参数的自定义对象：成员对象在进入构造函数 {} 之前就会被创建。 等你进到 B 构造函数的大括号里，a_obj 早就已经尝试构造完了，你在里面只能赋值，不能初始化。

class Person
{
private:
    const int id; // 示例1. const常量，一旦创建就不能修改
public:
    // Person() { id = 1001; } // ❌报错！id已经创建，不能赋值修改const
    Person() : id(1001) // ✅创建id的时候直接初始化
    {
    }
};

class Person
{
private:
    int& ref; // 示例2.引用必须定义时绑定变量，不能后期赋值
public:
    Person(int &a) : ref(a)
    {
    }
};

class Person
{
private:
    int age;
    const int id;
public:
  	// 多个成员变量初始化，需要注意的是初始化顺序是按照成员变量书写顺序
    Person(int a, int i) : age(a), id(i)  
    {
        // 这里可以写额外逻辑
    }
};

#include <iostream>
using namespace std;

class A
{
public:
    A(int x)
    {
        cout << "A带参构造 x=" << x << endl;
    }
};

class B
{
private:
    A a_obj; // A类型成员，A没有默认构造
public:
    // B()  // ❌ 报错！编译器尝试调用A无参构造，不存在
    B() : a_obj(66) // ✅初始化列表，指定调用A(int)
    {
        cout << "B的构造函数体" << endl;
    }
};

int main()
{
    B b;
    return 0;
}

2. 析构函数#

特点：

  • ~类名()，没有参数，没有返回值，只有一个析构函数，不能重载；
  • 对象销毁的那一刻，编译器自动调用；
  • 作用：清理资源，释放new出来的堆内存、关闭文件、释放网络连接，记录日志、保存状态等；
class Person
{
private:
    int age;
    char* buf; // 指针，将来指向堆内存
public:
    Person()
    {
        cout << "构造：对象出生" << endl;
        age = 0;
        buf = new char[100]; // 构造的时候，申请堆内存
    }
    ~Person()
    {
        cout << "析构：对象即将销毁，清理堆内存" << endl;
        delete[] buf; // 释放构造里申请的堆内存！防止内存泄漏
    }
};

3. 完整生命周期#

  1. 栈对象的完整生命周期： 构造函数 → 使用对象 → 析构函数 上述Person是栈对象，进入是调用构造函数，销毁时调用析构函数
void test()
{
    Person p; // 1. 创建对象 → 自动调用【构造函数】初始化，对象出生
    p.setAge(20);
    // ... 使用对象做业务逻辑
} // 2. 函数结束，离开作用域，p对象销毁 → 自动调用【析构函数】清理资源
  1. 堆对象 new /delete的生命周期
int main()
{
    Person* p = new Person(); // new：创建堆对象 → 自动调用构造函数
    p->setAge(20);

    delete p; // delete：销毁堆对象 → 自动调用析构函数！！
    p = nullptr;
    return 0;
}

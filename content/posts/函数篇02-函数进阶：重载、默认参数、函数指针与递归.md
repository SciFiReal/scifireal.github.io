## 1. 函数重载

函数重载解决的问题是在同一个作用域可以定义多个函数名相同，但参数列表必须不同（参数列表类型，数量，顺序不同），编译会根据实参调用合适的函数。

函数重置中相同的函数必须通过参数来区分，返回值不能区分

```c++
#include <iostream>
#include <cstring>
using namespace std;

// 重载版本1：打印整数
void print(int value)
{
    cout << "[整数] " << value << endl;
}

// 重载版本2：打印浮点数
void print(double value)
{
    cout << "[浮点数] " << value << endl;
}

// 重载版本3：打印字符串
void print(const char* str)
{
    cout << "[字符串] " << str << endl;
}

struct Device
{
    int id;
    char name[30];
    double temp;
};

// 重载版本4：打印设备结构体
void print(const Device& dev) // &是引用，这里可以理解为安全的“别名”
{
    cout << "[设备] ID=" << dev.id << " 名称=" << dev.name
         << " 温度=" << dev.temp << "度" << endl;
}

int main()
{
    print(1001);                // 自动匹配版本1（int）
    print(82.5);                // 自动匹配版本2（double）
    print("加热炉A");           // 自动匹配版本3（const char*）

    Device d = {1001, "加热炉A", 82.5};
    print(d);                   // 自动匹配版本4（Device结构体）
    return 0;
}
```

输出结果：

```txt
[整数] 1001
[浮点数] 82.5
[字符串] 加热炉A
[设备] ID=1001 名称=加热炉A 温度=82.5度
```

> 还有一个小知识点，指针`*`和引用`&`，`&`还有一个取地址的作用

```c++
int a = 10;

// 指针：存目标内存地址，可以为空，可以改指向
int* p = &a;   // p是独立变量，保存a的地址
*p = 20;       // 解引用修改a

// 引用：变量的别名，和原变量是一块内存，不能为空，不能换目标
int& r = a;    // r只是a的别名，r和a是同一个东西
r = 30;        // 直接修改a
```

深入理解引用和指针：

```c++

// 写法1：值传递（拷贝整个结构体，结构体大时浪费性能）
void printDev(Device dev) { cout << dev.deviceId; }

// 写法2：const指针（只读，需要判空）
void printDev(const Device* pDev) { if(pDev) cout << pDev->deviceId; }

// 写法3：const引用（推荐！只读、无拷贝、不用判空）
void printDev(const Device& dev) { cout << dev.deviceId; }
```

> 指针是传入一个地址，而引用底层也是传入一个地址，那引用有存在的必要吗？
>
> 1. 底层虽然大家都是传地址，但方式不一样，指针是可空（需要判空），可换指向；引用时强制绑定有效对象，不可空，不能改指向。
> 2. 引用的表达方式：这个参数一定存在，只是读取或修改这个已存在对象

## 2. 默认参数

需要注意三点：

1. 默认参数是在函数声明中给某些参数指定默认值，调用时可以不传入这些参数，直接用默认值。

2. 默认参数必须从右向左连续设置。

3. 默认参数写在函数声明中（头文件），不需要在定义函数中重复写。

   ```c++
   #include <iostream>
   using namespace std;
   
   // 声明中指定默认参数：默认温度阈值80度，默认压力上限1.2MP
   // 默认参数必须从右向左连续设置，不可与参数交叉
   void checkDevice(int deviceId, double temperature,
                    double tempLimit = 80.0, double pressureLimit = 1.2)
   {
       cout << "设备" << deviceId << ": ";
       if (temperature > tempLimit)
           cout << "温度" << temperature << "度 超过阈值" << tempLimit << "度!";
       else
           cout << "温度" << temperature << "度 正常";
       cout << endl;
   }
   
   int main()
   {
       checkDevice(1001, 75.0);          // 使用默认的温度阈值
       checkDevice(1002, 85.5);          // 使用默认阈值
       checkDevice(1003, 125.0, 120.0);  // 反应釜：自定义高温阈值
       checkDevice(1004, 28.5, 45.0);    // 冷却设备：低温阈值
       return 0;
   }
   ```

   输出结果：

   ```
   设备1001: 温度75度 正常
   设备1002: 温度85.5度 超过阈值80度!
   设备1003: 温度125度 超过阈值120度!
   设备1004: 温度28.5度 正常
   ```

## 3. 函数指针

1. 函数是一段代码，在内存中也是有地址的，函数指针指的是存函数的地址的变量

```c++
#include <iostream>
using namespace std;

int add(int a, int b)      { return a + b; }
int multiply(int a, int b) { return a * b; }
int subtract(int a, int b){ return a - b; }

// 函数指针类型别名：MathFunc 代表 接收两个int、返回int的函数指针
typedef int (*MathFunc)(int, int);  
// C++11将typedef改为using
// using MathFunc = int (*)(int, int);

int main()
{
    MathFunc op; // op 是函数指针变量，可以保存同类型函数的地址

    // 让op指向add函数
    op = add;
    cout << "10 + 5 = " << op(10, 5) << endl; // 通过函数指针调用

    // 让op指向multiply函数
    op = multiply;
    cout << "10 * 5 = " << op(10, 5) << endl;

    // 让op指向subtract
    op = subtract;
    cout << "10 - 5 = " << op(10, 5) << endl;

    return 0;
}
```

```c++
// 知识点：typeof：给已有数据类型起别名，简化数据类型书写

// 例子1
typedef int Age;
Age a = 20; // Age等价于int

// 例子2
typedef int (*MathFunc)(int, int);
MathFunc op; // 等价于 int (*op)(int,int);
```

2. 函数指针作为参数：把一个函数 “当作变量” 传给另一个函数，让这个函数内部可以动态调用你传进来的逻辑。这就是**策略模式**的基础：**主体框架固定，具体算法 / 策略外部传入，运行时切换策略**

```c++
#include <iostream>
using namespace std;

// 函数指针类型别名：接收两个int，返回int
using MathFunc = int (*)(int, int);

// 框架函数：固定流程，运算策略由参数传入
int calc(int a, int b, MathFunc strategy)
{
    return strategy(a, b); // 调用外部传进来的策略函数
}

// 不同策略
int add(int a, int b)      { return a + b; }
int multiply(int a, int b) { return a * b; }
int subtract(int a, int b){ return a - b; }

int main()
{
    cout << calc(10,5, add) << endl;      // 策略：加法
    cout << calc(10,5, multiply) << endl;  // 策略：乘法
    cout << calc(10,5, subtract) << endl; // 策略：减法
    return 0;
}
```

## 4. 递归

递归：本质就是函数自己调用自己。换句话来说把一个大问题分成相同问题的小问题，直到终止程序。

- 递归终止条件
- 递归调用本身
- 把所有结果合并

```c++\
// 求n!

int factorial(int n)
{
	if(n > 1)
	{
		return n * factorial(n - 1);
	}
	
	return 1：
}
```

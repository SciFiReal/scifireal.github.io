## 1. 一维数组

### 1.1 什么是一位数组？

数组的本质是什么？本质是一段连续的存储相同类型的内存空间。用于存放一组数据类型相同的变量，数组中的元素叫数组元素，通过数组下标来访问。

- 数组中类型统一，不能混合存放各种数据类型
- 数组下标从0开始，数组长度n，下标范围为0~n-1

### 1.2 数组的初始化

需要记住一点是，数组必须要初始化，防止读取脏数据（对自己代码毫无用处的数据）

- 完全初始化（已知所有元素数值）

  ```c++
  // 为何会用无符号字符数组呢，字符只占一个字节，减少不必要的空间浪费
  unsigned char deviceIds[5] = {1001, 1002, 1003, 1004, 1005};  
  ```

- 部分初始化（部分已知，知道数组长度，剩余元素编译器自动补0）

  ```c++
  int deviceIds[10] = {1001, 1002, 1003, 1004, 1005};
  ```

- 省略数组长度，由数组元素个数来反推（适用于数组元素不确定，后期要扩容）

  ```c++
  int deviceIds[] = {1001, 1002, 1003, 1004, 1005};
  ```

- 全零初始化，必须要这样处理，清除数组存在的脏数据

  ```c++
  int deviceIds[10] = {};
  ```

### 1.3 数组的遍历

数组的遍历就是循环遍历数组的每一个元素，通常是用for循环来实现。示例如下：

```c++
const int ARRAY_LENGTH = 10;  // 防止硬编码，多个数组，只需要一次修改
int deviceIds[ARRAY_LENGTH] = { 1001, 1002, 1003, 1004, 1005 };

for (int a = 0; a < ARRAY_LENGTH; a++)
{
	std::cout << "第" << deviceIds[a] << "次" << std::endl;
}
```

结果输出：

```text
第1001次
第1002次
第1003次
第1004次
第1005次
第0次
第0次
第0次
第0次
第0次
```

> - 数组中的元素在内存都是连续存放，读取速度极快
> - ==数组名的本质是数组的首个元素的首地址，不能直接打印数组全部元素，只能通过下标遍历==
> - 栈内存大小限制，局部数组大小受栈空间限制，不能设置超大数组

## 2. 二维数组

大家都知道除了线性数据，还有表格数据，二维数组就是来存储二维表格数据的。

### 2.1 初始化

- 数组元素，行列全部已知

  ```c++
  // 3行2列，分行书写，清晰明了
  double tempDate[3][2] = {
  {25.1, 26.3}, 
  {82.5, 27.9}, 
  {78.2, 30.1}
  };
  ```

- 数组元素，行列全部已知

  ```c++
  double tempDate[3][2] = {25.1, 26.3, 82.5, 27.9, 78.2, 30.1};
  ```

- 部分初始化，未赋值元素自动补0

  ```c++
  double tempDate[3][2] = {25.1, 26.3，82.5};
  ```

- 省略行数初始化（列数不能省略），编译器可以根据列数来推出行数

  ```c++
  double tempDate[][2] = {25.1, 26.3, 82.5, 27.9, 78.2, 30.1};
  ```

- 全零初始化

  ```c++
  double tempDate[3][2] = {};
  ```


### 2.2 遍历

需要两层遍历二位数字，外层遍历行，内层遍历列

```c++
const int ROW = 3;
const int COL = 2；

double tempDate[ROW][COL] = {
{25.1, 26.3}, 
{82.5, 27.9}, 
{78.2, 30.1}
};

// 两层for循环
for(int a = 0; a < ROW; a++) 
{
	for(int b = 0; b < COL; b++)
	{
		std::cout << tempDate[a][b] << std::endl;
	}
}
```



> 二维数组的底层特性：
>
> - 表明上有分行，其实在内存是连续存储，只是逻辑分行
> - 二维数组的下标都是从0下标开始

## 3. 字符数组

为何会有字符数组呢？一维和二维数组都是存储数值，字符数值是用来存储姓名，东西的名称。

### 3.1 字符数组基本定义和初始化

```c++
// 逐个字符初始化
char deviceName[5] = {'g','r','e','y','\0'}
// 直接字符串初始化（最常用）
char deviceName[12] = "hello world"
```

> 注意事项：
>
> - 单引号没有添加'\0'，需要手动添加，避免忘记
> - 双引号会自动添加'\0'，"hello world"字符串占12个字符大小
> - C++的硬性要求，C风格字符串必须以'\0'结束，空字符对应的ASCII值为0

---

### 3.2. C风格字符输入输出的高频坑定

- cin：输入字符串，自动会被空格、回车截断
- cin.getline：读取整行字符串

```c++
int num;
char ch[10];
char buf[100];
std::cin>>num;
std::cin>>ch;   // 不能读取带空格一整行，也不能读取回车
std::cin.getline(buf, 100); // 能读取空格，知道遇到回车为止
```

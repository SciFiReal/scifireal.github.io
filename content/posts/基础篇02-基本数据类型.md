## 1. C++三种基本整数数据类型

### 1.1 整型

我们只需要记住`int`基本整型，占用4个字节，大多数场景都是使用这个基本整型

```c++
#include <iostream>

int main() {

	int var = 5;
	std::cout << var << std::endl;  // 5
	return 0;
}
```

`int`表示的范围是-2^31^~2^31^-1，理由是计算机中是以补码的形成存储在内存空间中，原码`+0`和`-0`的存在导致补码形式存在两种，一种用来表达`0`数值，一种用来表达`-2^31^` 数值。

此外，`short`短整型（2个字节），`long`长整型（Windows 4字节，Linux 8字节），`long long`超长整型（8字节）。每一种整型有不同适用场景，在代码中的需要区分开来。

```c++
int var = 5; // 默认是int型
short s_var = 4; // 短整型
long l_var = 456L; // l/L
long long ll_var = 4567LL;  // ll/LL
```

> 需要在数值后加l/L，如果不加L，456被当作int型，会隐式转为long型，如果数值大于int型表示范围，会编译报错。需要在大数后面加入对应的符号。短整型为何不需要呢，因为输入的数值表示范围在int范围内，输入较大数值会直接报错。

### 1.2 字符型

`char`是字符类型，占1个字节，本质就是一个字节的整数，存的是ASCII值对应的数值，因此可以参与计算，比较判断。

```
char var = 'A'  // 等价于 char var = 65
char var_a = 65
```

ASCII值可见字符范围是0 ~ 127，`char`表示范围-128 ~ 127，可以存储全部ASCII值

示例：

```c++
#include <iostream>

int main() {

	char var = 65;
	char var_c = 'A';
	std::cout << var << std::endl; // A
	std::cout << var_c << std::endl;  // A
	std::cout << int(var_c) << std::endl;  // 65
	return 0;
}
```



### 1.3 布尔型

`bool`是一种状态判断类型，本质是1 bit，只表示两个值1和0，其实是用1 bit来表示布尔型，但内存寻址单位最小是字节，所以布尔型就占1个字节。

核心特性：1表示 `true`，0表示`false`；其它非0数值赋值`bool`，结果均为`true`；0赋值为`false`.

示例：

```c++
#include <iostream>

int main() {
	bool var = 65;
	bool var_c = 'A';
	bool var_b = 0;
	bool var_e = true;
	bool var_r = false;
	bool var_y = 1;
	std::cout << var << std::endl;    // 1
	std::cout << var_c << std::endl;  // 1
	std::cout << var_b << std::endl;  // 0
	std::cout << var_e << std::endl;  // 1
	std::cout << var_r << std::endl;  // 0
	std::cout << var_y << std::endl;  // 1
	return 0;
}
```

### 1.4 无符号和有符号

（1）无符号整型和有符号整形

`unsigned`无符号,表示无负数，`signed`有符号，支持正负

```
unsigned int var = 34;
signed int signed_var =34 // 等价与int signed_var =34，在整型中一般默认signed
unsigned short s_var = 23;
unsigned long l_var= 345UL;
unsigned long ll_var= 345ULL;   // 需要在大数后加入U/u
```

（2）无符号字符和有符号字符

`char`在不同的编译器平台会有不同：

- MSVC：`char` 默认 `signed char`，表示范围-128 ~ 127
- GCC：`char` 默认 `unsigned char`，表示范围0~255



### 1.5 数据类型转换

- **隐式转换**

  规则是**从低精度向高精度类型转换**，不会丢失精度，编译器自动完成；高精度向低精度转换，会丢失精度。

  优先级：`char < short < int < long < long long < float < double`

- **显示转换**

  是人为强制转换

  ```c++
  	int var = 65;
  	std::cout << var << std::endl;    // 65
  	std::cout << (char)var << std::endl;    // A
  ```

> 浮点转整型：直接截断小数，保留整数部分
>
> 整型转浮点：无误差
>
> 超大整型转浮点：超出有效精度范围，会丢失地位数据

## 2. 浮点型

浮点型最常用的`float`（4字节，单精度浮点型）,`double`（8字节，双精度浮点型）

注意事项

1. 浮点数值后不家f/F，默认是double类型，会发生隐式转换，double > float 丢失精度。

   ```c++
   float var = 0.23f;
   double d_var = 0.3435;
   ```

2. 有效位数的精度值

   float 和 double 是32 位和64位单精度浮点数 IEEE754，了解IEEE754可以自行去搜索。

   `float`的有效精度6 ~ 7位。`double`的有效精度15 ~ 16位。

3. 浮点类型无法精确计算存储所有小数，==底层原理是二进制科学计数法无法精准表示部分数比如0.1==，应该在逻辑判断不能用==来判断两个浮点数是否相等，采用区间判断，误差在极小阈值内即可判断相等（1e-6）。

4. 建议首先使用`double`类型，适合高频运算、迭代计算。

> `sizeof`用来计算数据类型与对象的所占的字节数
>
> ```c++
> int var = 65;
> double d_var = 0.2333;
> std::cout << sizeof(var) << std::endl;    // 4
> std::cout << sizeof(d_var) << std::endl;    // 8
> ```



## 3. 常量

- 字面量常量

  ```c++
  int a = 5;
  long b = 5L;
  unsigned int c = 7u;  // 这些都是字面量常量
  ```

- `const` 常量：可以修饰任意类型的变量，将其变为只读常量，初始化不能修改

  ```c++
  const double MAX_TEMP = 100.0; // 常量名全部大写，下划线，见名知意
  ```
